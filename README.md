# Spooky maze game


## Live demo



## About
An infinite maze game where each level is randomised and different every time you play. You must collect at least 5 ghosts throughout the map; they are coloured white before you can move on to the next level.

## How to run
Download the files and open index.html in a browser.

Python, mostly using the turtle module
